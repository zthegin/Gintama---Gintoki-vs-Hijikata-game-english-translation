    Try your opening edit
    
        
    Download the scene JSON. Put it beside the project files, then build a new local ROM from your original legally obtained ROM:
    
        
    python tools/build_ui.py --rom "original.nds" --cutscene "opening_scene.json" --out "local/opening-test.nds"
    
        
    This applies the exported opening together with the bundled field dialogue and graphics. Add --dialogue "your-batch.json" if you also want to test a downloaded field batch. Shorten any message the builder rejects, then download it again. Setup instructions.
