    Test your cutscene edits
    
        
    Download the JSON and put it in the project folder. Replace the example filenames below with your export and your own legally obtained ROM:
    
        
    python tools/build_ui.py --rom "original.nds" --cutscene "s02.json" --out "local/cutscene-test.nds"
    
        
    The build uses your edits for the selected script and includes the other bundled translations and graphics. Add --dialogue "your-batch.json" if you also want to test a downloaded field batch. Shorten any message the builder rejects, then download it again. Setup instructions.
