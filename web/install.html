English translation of Gintama: Gintoki vs. Hijikata!? Kabukichou Gintama Dai Soudatsusen!! for Nintendo DS.

Install the translation

You do not need to write or edit code. Copy the commands below and use your own ROM path.

Use Python 3.13 (recommended; Python 3.11 is also tested) and your own legally obtained, matching, unmodified ROM. This project provides no ROMs, unauthorized download links or help finding unauthorized copies. If you are unsure whether you may use a ROM, stop and check first. A matching checksum confirms compatibility, not ownership or permission.

On Windows, start with the short Python setup or the official installation guide. Python 3.10 is too old for the dependencies.

1. Open the project folder

Download and extract the project source. Rename the extracted folder to gintama and keep it in a short path, such as C:/Games/gintama, before creating .venv. Long paths can stop Python dependencies from installing on Windows. Open the folder containing README.md, requirements.txt and tools. On Windows, type powershell in File Explorer’s address bar and press Enter.

2. Run these commands on Windows

Replace the ROM path with yours. Keep the quotes around it. The commands use a project-local environment; you do not need to activate scripts or change PowerShell settings. 

py -3.13 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe tools/build_ui.py --rom "C:/Games/Gintama/original.nds" --out local/english.nds
Let a local coding assistant set it up

Claude Code, Codex or another assistant with local file access can follow the copyable setup request in the README. It must ask you for your own legally obtained ROM path. It must not find, download or upload game files.

For macOS/Linux, follow the installation guide.

3. Play the translated copy

The game is built on your device. GitHub checks the tools and builds this website; it does not receive your ROM or build a playable game. No ROM or resource pack is bundled.

Open local/english.nds in your emulator. Start it normally rather than loading an old save state. Your original ROM stays unchanged. Keep the rebuilt ROM and extracted game assets on your computer. Do not upload them to issues or pull requests, and remove personal file paths from public reports.

The build applies bundled English dialogue, graphics and UI labels. See the guide for current counts. Much of the game is still Japanese.

Test a dialogue edit from the website

Download the JSON from the dialogue editor after making your changes. Use the same setup as above, then replace both paths in this command: 

.\.venv\Scripts\python.exe tools/build_ui.py --rom "C:/Games/Gintama/original.nds" --dialogue "C:/Users/you/Downloads/my-batch.json" --out local/my-dialogue.nds

This uses your downloaded batch in place of the bundled field dialogue. Graphics, UI and the opening cutscene are still included. Keep the CSV too if you plan to submit a pull request; the local build only needs JSON. A successful build checks the fixed-size slots, but you still need to check how the wording looks in its game context.

Test an opening edit from the website

Use Opening, then download its JSON or copy it and save it as opening_scene.json. Keep every entry and English part in order.

.\.venv\Scripts\python.exe tools/build_ui.py --rom "C:/Games/Gintama/original.nds" --cutscene "C:/Users/you/Downloads/opening_scene.json" --out local/my-opening.nds

Replace both paths with yours. You can add --dialogue with a field-dialogue export to test both together. The builder checks source hashes, formatting controls, text width and fixed slots. Only the opening s01 cutscene is supported here.

Make a local BPS patch 
.\.venv\Scripts\python.exe tools/build_ui.py --rom "C:/Games/Gintama/original.nds" --patch local/english.bps

Keep local/english.bps and local/english.json together. Check the rights policy before sharing a patch.

Apply an existing patch kit

Extract the kit and open a terminal in its folder. Replace the example patch and manifest names with the ones supplied. On Windows, use Python 3.13: 

py -3.13 rom_patch.py apply --source "C:/Games/Gintama/original.nds" --patch translation.bps --manifest translation.json --output english.nds

If you are using the source project instead of a patch kit, use tools/rom_patch.py. On macOS/Linux, use python3 instead of py -3.13. This patch tool uses only the Python standard library. A patch changes only what its release notes list.

If something fails

  • Python not found: follow the Python setup linked above. Check py -3.13 --version on Windows or python3.13 --version on macOS/Linux.
  • Filename too long / WinError 206: extract a fresh copy to a shorter folder, then run the setup commands there. Create a new .venv rather than moving an existing one.
  • Wrong ROM: use the supported unmodified original. Renaming another file will not help.
  • Output exists: choose a new name, such as local/english-2.nds.

For custom labels, the supported checksum and more options, see docs/APPLY_PATCH.md in the source download.

Try a battle edit

Use Battle, load your own legally obtained original ROM, edit a record and download battle_translations.json.

.\.venv\Scripts\python.exe tools/build_ui.py --rom "C:/Games/Gintama/original.nds" --battle "C:/Users/you/Downloads/battle_translations.json" --out local/my-battle.nds

Your edit overlays the bundled translations. The original ROM is preserved; choose a new output filename each time.
