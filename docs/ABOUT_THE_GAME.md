# About the game and Gintama

## The Nintendo DS game

This project translates *Gintama: Gintoki vs. Hijikata!? Kabukichou Gintama Dai Soudatsusen!!*, an adventure game published by Banpresto for Nintendo DS in Japan on 14 December 2006. It is a single-player game.

The story takes place in Kabukicho. Players choose Gintoki’s route or Hijikata’s route and see its incidents from different sides. Battles use collectible Gin Tama: some deal damage through words, while others deliver physical attacks. The translation keeps the name **Gin Tama** for these items. Collecting every Gin Tama is an optional goal alongside the story.

Release details and the gameplay description are documented in [Nintendo’s original game listing](https://www.nintendo.co.jp/ds/software/avgj/index.html). [Sunrise’s launch announcement](https://www.sunrise-inc.co.jp/work/news.php?id=1614) also identifies the publisher, date and two protagonists.

These details identify the game, not every compatible cartridge revision. Before building, check the supported source checksum in [installation](APPLY_PATCH.md). For what is currently translated, see the [README](../README.md#current-progress).

## The manga and anime

*Gintama* began as a manga by Hideaki Sorachi. Its setting is an alternate Edo where aliens live alongside samurai and everyday life mixes old Japan with modern technology. Gintoki Sakata takes odd jobs with Shinpachi Shimura and Kagura through the Yorozuya. The television anime began on 4 April 2006.

The series moves between petty arguments, absurd comedy and more serious stories. That matters when translating: a line can be deliberately rude, a straight-faced response to a ridiculous situation, or sincere. Read the exchange around it before deciding how it should sound in English.

[VIZ’s series introduction](https://www.viz.com/gin-tama) introduces Sorachi and the premise. [TV Tokyo’s original episode archive](https://www.tv-tokyo.co.jp/anime/gintama/episodes/index_40.html) records the anime’s first broadcast and early stories.
